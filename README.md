# 🚚 Transp Logistics - MongoDB & .NET 6 MVC Project
A professional-grade logistics and cargo management system built with .NET 6 MVC and MongoDB. This project demonstrates the implementation of NoSQL databases in complex business workflows, featuring real-time tracking, dynamic cost calculation, and modular content management.

---

## 🏗️ Architecture Overview

The project is designed using a Folder-Based Monolithic Architecture, applying Separation of Concerns (SoC) to ensure maintainability and scalability within a unified project structure:

- **Entities:** Core domain models mapped to MongoDB collections.

- **DTOs (Data Transfer Objects):** Optimized data structures for secure communication between layers.

- **Service Layer:** Dedicated business logic handlers for managing CRUD operations and specific logistics rules.

- **Mapping:** Automated object-to-object mapping using AutoMapper.

- **ViewComponents:** Modular UI units for independent rendering of dynamic data like Testimonials and Sliders.

- **Settings:** Strongly-typed configuration management using the IOptions pattern for database connectivity.


## 🚀 Technical Stack

- **Framework:** .NET 6.0 (ASP.NET Core MVC)

- **Database:** MongoDB (NoSQL)

- **Mapping:** AutoMapper

- **Frontend:** Bootstrap 5, JavaScript (ES6+), HTML5, CSS3

- **Design:** Modern UI with Inter font family and Bootstrap Icons


## 🛠️ Core Functionalities

- **Advanced Shipment Tracking:** A sophisticated timeline interface for monitoring cargo status across five stages: Received, Sorting, In Transit, Delivery, and Delivered.

- **Interactive Cost Calculator:** A dynamic tool that calculates estimated shipping fees based on weight, dimensions, and commodity types in Euro (€).

- **Dynamic Content Management:** Fully customizable sections for Sliders, Customer Testimonials, FAQ, and Brand Partners.

- **Infrastructure:** Robust Dependency Injection (DI) setup using Scoped services for efficient resource management.
